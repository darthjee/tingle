# PHP entrypoint
Implement `entrypoint.php` (and helpers under `lib/` if it grows; mirror `docker/js_complexity/lib/`'s split by concern, e.g. input, staging, pdepend, output). It uses only the PHP standard library plus `vendor/autoload.php` for `Composer\InstalledVersions`. Implement image.md §4–§8 exactly:

1. **Input (§4):** read all of stdin. If it fails `mb_check_encoding($in, 'UTF-8')`, exit 1. Split on `\n`; a trailing `\n` does not start an extra line, and nothing is trimmed. Apply the refusal rules in order: `empty line`, `absolute path`, `path has a '..' segment`, `duplicate line`, `not a regular file under /src` (realpath must be inside `/src`), `unsupported extension` (lower-cased extension ≠ `php`), `Blade template`. Each refusal adds an `entrypoint` warning.
2. **Parse check (§5):** read the accepted file once from its real path and run `token_get_all($code, TOKEN_PARSE)`. On a `CompileError`, set `parse_error: true` and add a `php` warning `"<message> on line <line>"`; the file is not staged. Otherwise, copy the bytes to `/tmp/stage/<n>.php`.
3. **PDepend (§6):** only when something was staged. Remove any old `/tmp/pdepend/summary.xml`, create `/tmp/pdepend/` and `/tmp/pdepend-cache/`, then `proc_open` with the argument array `[/opt/tingle_php_complexity/vendor/bin/pdepend, --quiet, --summary-xml=/tmp/pdepend/summary.xml, /tmp/stage]`, cwd `/tmp`, and env plus `XDG_CACHE_HOME=/tmp/pdepend-cache`. Capture PDepend's stdout and stderr and copy them to stderr (stdout first). Handle failures per the §6 table: a non-zero exit is passed through, a signal gives exit 1, a missing XML gives exit 1, non-well-formed XML or a root other than `metrics` gives exit 1, an unknown path gives exit 1, a malformed unit gives exit 1. Scan the error block on PDepend's stdout with the regex from §6 to mark parse errors and add `pdepend` warnings; lines that don't match become path-less warnings.
4. **Merge (§7):** count class/trait methods (`Class::method`) and functions whose `file` is `/tmp/stage/<n>.php`, and ignore bare `<method>` elements. `pdepend` = `{ccn: sum, max_ccn, max_npath, min_mi (lowest finite mi, unrounded), lloc from the file entry}`, or `null` when there is no file entry. `functions` and `duplication` are `null` for every entry; `tool_versions.jscpd` is `null`. Keep the warnings in the §7 order. `max_npath` can exceed 2^53, so keep it as an int (or emit it so it survives JSON) per README deviation 10.
5. **Output and exit (§8):** `json_encode` with `JSON_THROW_ON_ERROR | JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE`, followed by `\n`, on stdout. Nothing else goes to stdout, ever. On any failure, write `tingle_php_complexity: <reason>` on stderr and exit 1 (or pass through PDepend's status). Empty stdin prints empty `files`/`warnings` with the versions filled and exits 0. Write only under `/tmp`.
