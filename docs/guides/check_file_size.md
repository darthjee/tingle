# `tingle check_file_size`

This command has moved to `tingle code_check file_size` and the old name is
deprecated. It still works, with the same options, output and exit codes,
but it prints a warning on stderr:

```
Warning: 'tingle check_file_size' is deprecated; use 'tingle code_check file_size'.
```

The alias will be removed in a future release. See
[Migrating from `check_file_size`](code_check.md#migrating-from-check_file_size)
for how to switch, and the
[`tingle code_check file_size`](code_check/file_size.md) guide for the
command itself.
